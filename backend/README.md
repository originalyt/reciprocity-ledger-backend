# Reciprocity Ledger Backend

后端实现以 `doc` 目录中的需求、接口和开发指导文档为准。

## 运行说明
1. 启动前配置 `DB_URL`、`DB_USERNAME`、`DB_PASSWORD`
2. 先执行 `sql/baseline.sql`
3. 在 `backend/` 目录下运行 `mvn spring-boot:run`
